The first CyberWarMachine theme for Hermes Desktop. New chats get a single soft blue sweep over the monument. The ground haze keeps drifting until you start a conversation. With Reduce Motion enabled or WebGL unavailable, the scene stays still.

**Install:** Download `hermes-cwm-theme-v0.1.0.zip` from Assets and follow the [installation and Appearance guide](https://github.com/cygnostik/hermes-cwm-theme#install). No build is needed. Start in Dark mode with a wide, empty main chat to see the full backdrop.

[View the screenshot and motion demo](https://github.com/cygnostik/hermes-cwm-theme#cyberwarmachine-for-hermes-desktop). Both were captured from the plugin running in the Desktop preview.
